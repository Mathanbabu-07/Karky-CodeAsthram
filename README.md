# Blockly-based Python Learning System

A Blockly-based Python code generator built with React and Vite, designed as a comprehensive learning system for students.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open in browser:
   ```
   http://localhost:5173
   ```

You can drag blocks, generate Python code, and see the output. This system is designed to teach Python programming from basic to advanced levels through a visual, block-based interface.
