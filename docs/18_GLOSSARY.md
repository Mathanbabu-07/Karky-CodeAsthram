# Glossary

- **Blockly workspace:** mutable graph of blocks rendered in the editor.
- **Block schema:** block identity, fields, inputs, connections, mutation and semantic meaning.
- **Generator handler:** function converting a block instance into target source fragment.
- **Toolbox:** categorized list of block types a user can create.
- **Suite/module:** current catalog grouping in `toolbox/suites.js`.
- **Mutation / extra state:** serialized data that changes a block's shape (for example, number of inputs).
- **Workspace envelope:** proposed versioned metadata wrapper around XML.
- **Language descriptor:** proposed complete target capability record.
- **IR:** intermediate representation; a target-neutral generation form proposed for scalable languages.
- **Runner:** service/runtime that executes generated code.
